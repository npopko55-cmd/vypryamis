# Материалы дизайна

Макет кабинета на лендинге — компонент `PhonePreview` в `frontend/src/App.tsx`, оформленный по предоставленному DOCX. Исходная картинка заменена вёрсткой, чтобы убрать значки с фигурой человека и сохранить единый стиль иконок.

`frontend/public/trainer-poster.webp` — чистая версия фотографии из предоставленного настольного макета, подготовленная встроенным Imagegen. Это обложка интерфейса, не учебный видеоролик. При подключении реальных видео её можно заменить официальной обложкой.

Промпт: Extract only the photo of the same male trainer in white T-shirt and jeans standing in the same wood-and-grey home office. Preserve his face, identity, hairstyle, body, clothing, pose and interior. Return a clean landscape 16:9 photograph. Remove all UI, play button, text, labels, calendar, borders and avatar. Seamlessly reconstruct the shirt. Natural soft lighting. No new objects, text, icons, overlays or watermark.

Иконки — Lucide, шрифты — системные; интерфейс не зависит от загрузки Google Fonts. Превью создано по предоставленным материалам. Права на фотографии и финальные тексты подтверждает владелец перед публикацией.
