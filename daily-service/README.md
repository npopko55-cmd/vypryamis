# Выпрямись

Веб-сервис ежедневных разминок: лендинг, личный кабинет, 21-дневные циклы, месяц доступа, полные тренировки, оплата через GetCourse, письма и админка.

Код нового сервиса размещается в `daily-service/` существующего репозитория. Команды ниже выполняются из этой папки. Прежний лендинг репозитория хранится отдельно.

## Быстрый запуск для разработки

Требуются Python 3.12+ и Node.js 22. Для локального просмотра достаточно SQLite. Настоящие оплаты и видео требуют подключения внешних аккаунтов.

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r backend/requirements.txt
cd backend
alembic upgrade head
python -m app.manage seed
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

В другом терминале:

```sh
cd frontend
npm ci
npm run dev
```

Откройте `http://localhost:5173/`, демо кабинета — `/demo`. Vite проксирует `/api` на порт 8000. Базовый PUBLIC_URL для разработки — `http://localhost:5173`; при другом origin настройте переменную окружения.

Администратор создаётся интерактивно, пароль не передаётся через аргументы:

```sh
cd backend
python -m app.manage admin --email admin@your-domain.ru
```

## Что работает

- Регистрация, email/пароль, cookie-сессии на 90 дней с обновлением, смена и восстановление пароля, подтверждение почты без блокировки оплаты, выход со всех устройств.
- Календарь, открытие уроков по часовому поясу, архив открытых уроков до конца доступа, раннее и позднее продление, сохранение истории после окончания доступа.
- Серверный накопительный прогресс, защита от повторной отправки фрагмента и одновременного начисления с нескольких устройств.
- Создание заказа GetCourse, callback с секретом в заголовке, идемпотентная выдача, отзыв по возврату, ручная привязка, почасовая сверка Export API.
- Однократная пробная полная тренировка, платный доптариф с проверкой основного доступа.
- Почтовая очередь в PostgreSQL, повторные попытки, напоминания в 09:00 местного времени, отписка, Unisender Go Web API.
- Админка: пользователи, события, выдача доступа, оплаты, видео и советы, две кривые удержания, исключение тестовых аккаунтов.
- Docker Compose, Caddy HTTPS, миграция Alembic, резервное копирование, CI.

- [Подключение GetCourse](docs/GETCOURSE.md)
- [Развёртывание и эксплуатация](docs/DEPLOYMENT.md)
- [Правила доступа и аналитики](docs/ARCHITECTURE.md)
- [Материалы дизайна](docs/ASSETS.md)

Нужны домен, GetCourse (адрес, ключ API, коды двух предложений, процесс callback), Unisender Go с подтверждённым доменом, Kinescope с защищёнными видео и российский сервер. В админке создаются черновики трёх циклов. Продажи цикла закрыты, пока все 21 видео не опубликованы. Бесплатное демо содержит только пример интерфейса; фиктивных оплат и учебных роликов нет.

Страницы оферты, возврата, политики и согласия подготовлены как проекты. Перед продажами владелец заполняет реквизиты, контакт и утверждает условия. Платёжные данные вводятся на стороне GetCourse; настройки чеков выполняются там же.

## Проверки

```sh
cd backend
pytest -q
cd ../frontend
npm run build
```

Тесты покрывают авторизацию, CSRF, доступы и часовые пояса, оплату и возвраты, повторы callback, стоимость, владение заказом, накопление секунд и дубли фрагментов, ограничение параллельных просмотров, одноразовый сброс пароля, DRM-доступ и расчёт когорт.

Тестовые внешние ответы подменяются. Реальная покупка, доставка писем, DRM и Safari на физическом iPhone проверяются после подключения аккаунтов; они не считаются подтверждёнными локальными тестами.
